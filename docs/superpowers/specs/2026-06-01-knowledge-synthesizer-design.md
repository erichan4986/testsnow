# Knowledge Synthesizer 设计规格：主题化综合叙事

> 日期：2026-06-01
> 目标：将报告从"来源导向"改造为"主题导向"，用 LLM 综合多源信息生成连贯叙事，同时保留引用源机制

---

## 背景与动机

当前报告呈现的是"采集筛选后的成果"——雪球帖子、知乎文章、研报、公告等各自独立展示。读者需要在不同板块之间来回跳跃，才能拼凑出对一只股票的全貌理解。

例如，关于"圣邦股份估值是否合理"：
- 估值板块给了 PE/PB 数字
- 精品帖子里有散户说"太贵了"
- 知乎文章里有分析师说"成长能消化"
- 研报里机构给了目标价

这些信息散落在 4-5 个独立板块中，没有综合视角。

本设计引入 **Knowledge Synthesizer**，将多源信息按主题维度合成连贯叙事，让报告从"信息陈列"升级为"分析解读"。

---

## 设计约束

1. **保留引用源**：每个数字、事实、观点必须有 `[^n]` 标注，可追溯来源
2. **可验证性**：LLM 综合的内容不能编造数据，只能基于输入内容推理
3. **降级兼容**：LLM 不可用时，回退到现有板块展示方式
4. **增量更新**：不破坏现有采集 pipeline，只改造报告生成阶段

---

## 新报告板块结构

| # | 板块 | 说明 | 数据来源 |
|---|------|------|----------|
| 1 | 综合评分与推荐 | 量化评分 + 仓位建议 | 全部数据 |
| 2 | 估值与业绩预测 | 保留现有，增强叙事 | 实时行情 + 一致预期 |
| 3 | **产业逻辑与竞争格局** | 【合成】供需、竞争、国产替代、涨价周期 | 雪球 + 知乎 + 新闻 + **公众号** |
| 4 | **业绩基本面追踪** | 【合成】营收、利润、毛利率、订单变化 | 研报 + 公告 + 帖子 + **公众号** |
| 5 | **估值争议与市场分歧** | 【合成】多空双方观点、关键分歧变量 | 全部来源 |
| 6 | **资金面与情绪跟踪** | 【合成】主力动向、散户情绪、北向资金 | 资金流向 + 社区情绪 + **公众号** |
| 7 | **关键事件与催化剂** | 【合成】公告、政策、订单、行业事件 | 公告 + 新闻 + 帖子 + **公众号** |
| 8 | 风险综合评估 | 保留现有，增强 | 全部数据 |
| 9 | 信息来源汇总 | 所有 `[^n]` 引用对应的完整来源列表 | 自动收集 |

**被合并的旧板块**：
- "知乎内容精选" → 拆分到产业逻辑 / 业绩基本面 / 估值争议
- "精品帖子深度解读" → 拆分到对应主题
- "市场情绪与竞争格局" → 合并到产业逻辑 + 资金面
- "关键评论摘录" → 融入估值争议

## LLM Prompt 设计

以"估值争议与市场分歧"为例：

```
你是资深半导体行业分析师。请基于以下多源信息，对圣邦股份的估值争议进行综合解读。

要求：
1. 写一段 300-500 字的连贯分析，不要分点罗列
2. 每个关键数字和事实后面标注 [^n] 引用
3. 必须覆盖：看多方的核心论据、看空方的核心论据、双方分歧的关键变量
4. 最后给出一个中性的综合判断
5. 不要编造数据，只能基于以下信息

信息来源：
[1] 标题: xxx | 来源: 雪球 | 作者: xxx | 内容: ...
[2] 标题: xxx | 来源: 知乎 | 作者: xxx | 内容: ...
[3] 标题: xxx | 来源: 研报 | 机构: xxx | 内容: ...
...
```

LLM 输出示例：
```
市场对圣邦股份估值的分歧主要集中在成长性能否消化当前高估值。看多者认为，公司 Q1 收入同比增长 40% 至 11 亿元[^1]，且模拟芯片涨价周期下毛利率稳定在 51.6%[^2]，Forward PE 有望从 108 降至 81[^3]。国信证券研报指出，收入规模效应将加速利润释放[^4]。

但看空方指出，当前 PE(TTM) 108 已显著高于行业均值，且杰华特在 MOS 领域的竞争正在加剧[^5]。有行业专家认为圣邦的 MOS 产品"从性能和身份证明都无法撼动杰华特"[^6]，这可能压缩公司毛利率提升空间。

双方分歧的关键变量在于：涨价周期能否持续（看多依赖于此）以及新品放量进度（看空担忧于此）。综合来看，估值合理性取决于未来两个季度的毛利率走势和订单能见度。
```

## 引用机制

### 引用格式
- 叙事中：`[^1]`、`[^2]` 等上标格式
- 每板块末尾：自动列出该板块使用的所有引用

### 引用源信息结构
```python
{
    1: {
        "title": "一季度收入创季度新高...",
        "source": "国信证券研报",
        "author": "",
        "url": "",
        "date": "2026-05-20",
    },
    2: {
        "title": "圣邦股份,未来10年无悬念!",
        "source": "知乎",
        "author": "浪哥财经",
        "url": "https://zhuanlan.zhihu.com/...",
        "date": "2026-04-03",
    }
}
```

### 引用去重
- 同一份来源在不同主题中被引用时，使用相同的编号
- `source_index` 在整个报告级别统一管理

## 降级策略

当 LLM 不可用时：
1. `KnowledgeSynthesizer` 检测 `_client` 为 None
2. 返回空字符串，不生成合成板块
3. `stock_reporter.py` 回退到现有板块展示方式（知乎精选、精品帖子等）
4. 报告结构降级为旧版 12 板块

---

## 错误处理

| 场景 | 处理 |
|------|------|
| LLM API 超时 | 重试 1 次，仍失败则跳过该主题合成 |
| LLM 输出格式异常（无 [^n] 引用） | 用正则提取，缺失引用则标注 `[来源未标注]` |
| 某主题无足够信息（<3 条） | 跳过该主题合成，输出"该维度信息不足" |
| 引用编号不连续 | 不报错，按实际出现顺序整理 |
