# 技术面价格目标与触发条件设计

## 背景

当前技术面分析板块已支持趋势判断（ADX/MA）、动量指标（RSI/MACD/StochRSI/CCI/Williams %R）、波动率（ATR）、量价配合（OBV）及形态识别（双顶/双底/支撑阻力）。但缺少**量化的价格目标**和**严格的触发/失效条件**，导致报告读者无法将技术分析转化为可操作的中长期判断。

## 目标

为每只股票生成一份**多时间框架、多方法交叉验证**的中长期价格目标判断，包含：
- 三档价格目标（保守/基准/激进）
- 明确的触发买入条件
- 明确的止损/失效条件
- 时间预期
- 置信度评级

## 核心设计：A+B+C 融合框架

### 1. 多源输入层

| 数据源 | 用途 | 方法 |
|-------|------|------|
| **日K 120天**（现有） | 短期形态 + 精确入场点 | 形态识别(A) + 波段枢轴(B) |
| **周K 72周**（新增） | 中期大方向 + 大结构目标 | 形态识别(A) + 斐波那契扩展(B) |
| **共振引擎(C)** | 信号过滤 + 置信度评级 | 日线时机 × 周线方向 |

**数据源实现**：
- A股：`akshare.stock_zh_a_hist(symbol, period="weekly", ...)` 拉周K
- 港股：优先 Wind CSV，akshare `stock_hk_hist` 作为备选，字段做统一映射

### 2. 分析方法

#### 2.1 形态测距（A）
- **日K**：双顶/双底/头肩等，颈线突破后按形态高度测距
- **周K**：同样的形态识别逻辑应用于周K，得到中期大目标
- **公式**：目标价 = 颈线价 ± 形态高度（顶底到颈线的垂直距离）

#### 2.2 斐波那契扩展（B）
- **波段识别**：使用 Zigzag 指标自动找主要波段
  - 日线：最小转折幅度 **5%**
  - 周线：最小转折幅度 **10%**（基线，高波动芯片股可上调至 **12%**）
- 取最近 **2-3 个主要波段** 分别计算扩展目标，检查是否形成**斐波那契汇聚区**
  - **汇聚定义**：≥2个波段的同向扩展位落在 **3%价格区间** 内（如波段A的1.272位=145.2，波段B的1.272位=147.8，价差1.8%≈汇聚）
  - 汇聚度越高，该目标位权重越高
- 三档扩展位：1.0（保守）、1.272（基准）、1.618（激进）
- 回撤位：0.382/0.5/0.618 作为支撑/阻力参考

#### 2.3 多时间框架共振（C）
- **日线**：MACD金叉/死叉、RSI超买超卖、突破确认
- **周线**：ADX趋势方向、+DI/-DI相对位置、大形态完整性
- **共振规则**：日线与周线方向一致时给出目标，冲突时输出"观望"

### 3. 目标合成（标准化公式）

摒弃模糊的"权重60/40"，建立**标准化合成表**：

| 场景 | 保守目标 | 基准目标 | 激进目标 |
|------|---------|---------|---------|
| **日K形态 + 周K形态 同向**（共振） | 周线Fib1.0位、日K颈线、近期筹码密集区中的**较低者**（看多） | 日K形态测距值与周线Fib1.272扩展位的**均值** | 周线Fib1.618扩展位 |
| **仅一方有形态** | 有形态方的颈线 / 无形态方的Fib1.0位，取较低者 | **有形态方**的形态测距值为主，另一方Fib1.272仅作验证 | 有形态方测距 × 1.3 或 周线Fib1.618，取合理者 |
| **双方都无形态，只有波段** | 最近波段Fib1.0位 | 最近波段Fib1.272位 | 最近波段Fib1.618位 |
| **方向冲突** | — | **输出"观望"**，不生成目标 | — |

**激进目标上限**：不超过当前价格的 **+50%**（科技股放宽至 **+60%**）。若斐波那契1.618超出此范围：
- 报告中仍显示原扩展位价格，但标注 **"（久远，暂不可达）"**
- 该目标**不作为当期操作依据**
- 置信度评级**上限锁为"中"**（即使其他因子得分高，超远目标降低整体可信度）

### 4. 盈亏比过滤

价格目标生成前必须先过盈亏比关卡。由于实际触发价通常高于当前价，用**预估触发价**（颈线 + 0.3×ATR）计算更贴近实战：

```
预估触发价 = 颈线价 + 0.3 × 日线ATR（看多时）
预估止损价 = 颈线价 - 1.5 × 日线ATR（入场前保守估算，回避尚未产生的突破K线）
潜在收益 = |保守目标 - 预估触发价|
初始风险 = |预估触发价 - 预估止损价|
IF 潜在收益 / 初始风险 < 1.5:
    → 下调为 "关注/不操作"，不输出具体目标价
    → 报告中提示 "形态存在但盈亏比不足，等待更好的入场点"
```

> **为什么用预估触发价而非当前价？** 实际买入点通常在颈线突破确认后，而非当前位置。用触发价计算能更真实反映入场时的风险收益比，避免"当前看似盈亏比很好，但突破后才发现止损太大"的陷阱。
>
> **为什么止损用颈线-1.5×ATR而非突破K线低点？** 突破K线在入场前尚未产生，无法引用。颈线-1.5×ATR是更保守的预估算，实际入场后动态替换为 `max(突破K线低点, 颈线-1.5×ATR)`。

### 5. 触发条件（四重确认）

| 维度 | 触发条件 |
|------|---------|
| **价格行为** | 日线**收盘价 > 颈线**，且该K线**实体完全位于颈线上方**（开盘价和收盘价都在颈线上方），且**实体高度 ≥ 0.3×ATR** |
| **趋势** | 周线ADX > 25 且 +DI > -DI |
| **量能** | 突破日成交量 > 前5日成交量**中位数** × 1.5，且**量比（当日量/前5日中位数）> 1.5**，且突破日成交金额 ≥ **A股1亿元 / 港股3000万港币** |
| **动量确认** | 见下表「动量过滤规则」 |

#### 动量过滤规则（触发时即时评估）

突破当日的日线动量指标用于过滤假突破，规则如下：

| 指标 | 状态 | 对触发的影响 | 理由 |
|------|------|-------------|------|
| **RSI(14)** | 40–70 | ✅ 正常触发 | 健康动能区间 |
| **RSI(14)** | > 70 | ⚠️ 降级为"谨慎观察" | 超买区突破，动能可能耗尽，需等待回踩确认 |
| **RSI(14)** | < 35 | ✅ 优质触发（放宽实体高度要求） | 超卖区反弹，筹码结构干净，即使实体略小也可接受 |
| **MACD** | 金叉 + 柱线扩张 | ✅ 确认加分 | 动量与价格同向加速 |
| **MACD** | 金叉 + 柱线收缩 | ⚠️ 正常触发 | 动量减弱，需量能补足 |
| **MACD** | 死叉 | ❌ 触发否决 | 趋势与动量背离，即使形态突破也不应追 |
| **KDJ** | 金叉 | ✅ 辅助确认 | 与MACD/RSI共振时可信度更高 |
| **KDJ** | 死叉 | ⚠️ 警告但不否决 | 单独KDJ死叉不触发否决，仅作为风险提示 |
| **MA排列** | 5日>20日>60日 | ✅ 支撑确认 | 价格在短期/中期均线上方，趋势结构完整 |
| **BOLL** | 开口向上 + 价格沿上轨 | ✅ 强势信号 | 波动率配合，突破有效性高 |

> **否决优先级**：MACD死叉 > RSI>70降级 > 其他仅为加分/减分。即：MACD死叉直接否决触发，无论形态多完美。

### 6. 止损/失效条件

| 类型 | 条件 |
|------|------|
| **初始止损** | 突破K线的**低点** 或 **颈线往下1.5×ATR**，取较高者（限制最大亏损） |
| **跟踪止损**（入场后） | 入场后**最高收盘价**回撤超过 **2×日线ATR** 时触发（用收盘价避免盘中毛刺洗盘） |
| **趋势失效** | 周线ADX从**过去26周内峰值回落超过10点** 且 **+DI下穿-DI** |
| **量能失效** | 价格创**20日新高**但**OBV未同步创20日新高**（量价背离）；或 **连续5个交易日** 量能低于20日均量 **且** 价格跌破10日线 |
| **形态失效** | 日线收盘价反向跌破形态起点或前低支撑 |

### 7. 置信度体系（多因子加权）

摒弃"仅看形态有无"的简单二分法，改为**六因子加权评分**：

| 因子 | 权重 | 评分标准 |
|------|------|---------|
| **时间框架共振** | 30% | 日K与周K同向=10分 / 一方有形态另一方只有波段=6分 / 方向冲突=0分 |
| **形态完整性** | 20% | 颈线触及2次=10分（标准双底/双顶） / ≥3次=8分（多次触及反而增加假突破复杂度，需降低权重）；形态规模占近期波动比例越大分数越高 |
| **突破质量** | 20% | 实体完全过颈线+实体≥0.5ATR=10分 / 实体过颈线但<0.5ATR=6分 / 仅收盘价过颈线=3分 |
| **周线趋势强度** | 15% | ADX>30且+DI>-DI=10分 / ADX 25-30=7分 / ADX 20-25=4分 / <20=0分 |
| **动量综合** | 5% | 见下表「动量评分细则」 |
| **斐波那契汇聚** | 10% | ≥2个波段汇聚=10分 / 1个波段=5分 / 无=0分 |

**动量评分细则（满分10分）**：

| 指标状态 | 得分 | 说明 |
|---------|------|------|
| MACD金叉 + 柱线扩张 | +4 | 动量加速，最佳 |
| MACD金叉 + 柱线收缩 | +2 | 动量减弱，观望 |
| MACD死叉 | 0 | 直接拉低动量分 |
| RSI 40–60 | +3 | 健康蓄力区间 |
| RSI 60–70 | +1 | 偏热，动能有限 |
| RSI > 70 | 0 | 超买，无分 |
| RSI < 40 | +3 | 超卖反弹，筹码干净 |
| KDJ金叉 | +2 | 辅助确认 |
| KDJ死叉 | 0 | 不单独否决但无分 |
| MA多头排列(5>20>60) | +1 | 趋势支撑 |

> 动量综合分 = min(上述各项得分之和, 10)。该因子权重仅5%，**不主导**置信度，但MACD死叉时可将总分拉低0.5–1.0分，有效降低假突破的置信度。

**置信度映射**：
- 总分 ≥ 8.0：**高**
- 总分 6.0-7.9：**中**
- 总分 4.0-5.9：**低**
- 总分 < 4.0：**观望**

> **激进目标超限时的置信度处理**：若激进目标超当前价+50%（科技股+60%），标注"久远，暂不可达"，且**置信度上限锁为"中"**，即使六因子总分≥8.0。

### 8. 时间预期（基于ATR估算）

摒弃主观时间段，改为**波动率推导**：

```python
def estimate_time(target_price, current_price, daily_atr, 
                  macd_momentum="flat", rsi=50):
    """
    估算到达目标价所需时间范围
    基础：价格距离 / ATR = 理论最少K线数 × 安全系数(1.5~2)
    动量修正：MACD柱线斜率和RSI区间对时间进行微调
    """
    distance = abs(target_price - current_price)
    min_days = distance / daily_atr
    base_low, base_high = min_days * 1.5, min_days * 2
    
    # 动量修正系数
    multiplier = 1.0
    if macd_momentum == "expanding":
        multiplier *= 0.85      # 动量加速，时间缩短
    elif macd_momentum == "contracting":
        multiplier *= 1.25      # 动量减弱，时间延长
    
    if rsi > 65:
        multiplier *= 1.1       # RSI偏热，动能可能提前耗尽
    elif rsi < 40:
        multiplier *= 0.9       # RSI蓄力，动能充足
    
    return base_low * multiplier, base_high * multiplier
```

> **MACD柱线斜率判定**：连续3日柱线绝对值递增 = "expanding"（扩张），连续3日递减 = "contracting"（收缩），否则 "flat"。

### 斐波那契扩展
```python
def fib_extension(low, high, level):
    """从波段低点到高点的斐波那契扩展"""
    return high + (high - low) * (level - 1)
    # level: 1.0, 1.272, 1.618
```

### 形态测距
```python
def pattern_target(neckline, top, is_bullish):
    """双顶/双底测距"""
    height = abs(top - neckline)
    return neckline + height if is_bullish else neckline - height
```

### 置信度评分
```python
def confidence_score(resonance, pattern_quality, breakout_quality,
                     weekly_adx, momentum, fib_convergence) -> float:
    """六因子加权评分，返回0-10分"""
    return (resonance * 0.30 +
            pattern_quality * 0.20 +
            breakout_quality * 0.20 +
            weekly_adx * 0.15 +
            momentum * 0.05 +
            fib_convergence * 0.10)
```

## 边界情况处理

1. **无足够历史数据**（新股或停牌）：跳过价格目标板块，报告标注"数据不足"
2. **盈亏比不达标**：输出"关注/不操作"，提示等待更好入场点
3. **股价处于历史极端位置**：激进目标超±50%（科技股60%）时保留原扩展位但标注"久远目标/暂不可达"
4. **港股支持**：通过 Wind CSV 导入周K数据，接口层统一字段映射
5. **横盘无趋势**：ADX < 20 持续超过4周 且 BOLL带宽(上轨-下轨)/中轨 < **8%**（芯片股可放宽至10%），自动输出"震荡格局，暂不做目标"

## 阈值速查表

| 项目 | 规则 |
|------|------|
| 触发量能 | > 前5日成交量中位数 × 1.5，且 量比 > 1.5，且 金额 ≥ A股1亿/港股3000万港币 |
| 突破确认 | 收盘价 > 颈线，且 实体完全在颈线上方，且 实体高度 ≥ 0.3×ATR |
| 初始止损 | 入场后：突破K线低点 或 颈线 - 1.5×ATR，取较高者 |
| 跟踪止损 | 入场后最高收盘价回撤超过 2×日线ATR |
| 盈亏比过滤 | 潜在收益 / 预估初始风险 ≥ 1.5（预估止损=颈线-1.5×ATR） |
| ADX失效 | 过去26周内峰值回落 > 10 且 +DI下穿-DI |
| 量能失效 | 创20日新高但OBV未同步创新高；或连续5日低于20MA均量且跌破10日线 |
| 斐波那契上限 | 激进目标 ≤ 当前价 +50%（科技股+60%），超远目标标注"久远"且置信度上限锁"中" |
| BOLL横盘 | 带宽(上轨-下轨)/中轨 < 8%（芯片股10%）且ADX<20持续4周 |
| RSI触发过滤 | 40–70=正常触发；>70=降级谨慎观察；<35=优质触发（放宽实体高度） |
| MACD触发否决 | 死叉直接否决触发，无论形态/量能/趋势如何 |
| KDJ辅助 | 金叉=辅助确认；死叉=警告但不否决 |
| MA支撑 | 5日>20日>60日多头排列=触发加分 |
| BOLL强势 | 开口向上+价格沿上轨=强势突破确认 |
| MACD时间修正 | 柱线连续3日扩张=时间×0.85；连续3日收缩=时间×1.25 |
| RSI时间修正 | >65=时间×1.1；<40=时间×0.9 |
| Zigzag参数 | 日线5%，周线10%（基线，高波动芯片股可调12%） |
