# 技术面价格目标与触发条件设计

## 背景

当前技术面分析板块已支持趋势判断（ADX/MA）、动量指标（RSI/MACD/StochRSI/CCI/Williams %R）、波动率（ATR）、量价配合（OBV）及形态识别（双顶/双底/支撑阻力）。但缺少**量化的价格目标**和**严格的触发/失效条件**，导致报告读者无法将技术分析转化为可操作的中长期判断。

## 目标

为每只股票生成一份**多时间框架、多方法交叉验证**的中长期价格目标判断，包含：
- 三档价格目标（保守/基准/激进）
- 明确的触发买入条件
- 明确的止损/失效条件
- 时间预期
- 置信度评级

## 核心设计：A+B+C 融合框架

### 1. 多源输入层

| 数据源 | 用途 | 方法 |
|-------|------|------|
| **日K 120天**（现有） | 短期形态 + 精确入场点 | 形态识别(A) + 波段枢轴(B) |
| **周K 72周**（新增） | 中期大方向 + 大结构目标 | 形态识别(A) + 斐波那契扩展(B) |
| **共振引擎(C)** | 信号过滤 + 置信度评级 | 日线时机 × 周线方向 |

**数据源实现**：`akshare.stock_zh_a_hist(symbol, period="weekly", ...)` 已验证可拉周K数据。

### 2. 分析方法

#### 2.1 形态测距（A）
- **日K**：双顶/双底/头肩等，颈线突破后按形态高度测距
- **周K**：同样的形态识别逻辑应用于周K，得到中期大目标
- **公式**：目标价 = 颈线价 ± 形态高度（顶底到颈线的垂直距离）

#### 2.2 斐波那契扩展（B）
- 找主要波段（显著低点→高点 或 高点→低点）
- 三档扩展位：1.0（基准）、1.272（激进1）、1.618（激进2）
- 同时计算回撤位：0.382/0.5/0.618 作为支撑/阻力参考

#### 2.3 多时间框架共振（C）
- **日线**：MACD金叉/死叉、RSI超买超卖、突破确认
- **周线**：ADX趋势方向、+DI/-DI相对位置、大形态完整性
- **共振规则**：日线与周线方向一致时给出目标，冲突时输出"观望"

### 3. 目标合成与置信度

```
IF 日K形态 与 周K形态 同向
   → 形态测距权重 60%，斐波那契权重 40%
   → 置信度 = "高"（双时间框架确认）

ELIF 仅一方有形态
   → 有形态方权重 40%，另一方斐波那契 60%
   → 置信度 = "中"（单形态验证）

ELIF 双方都无形态，只有波段
   → 纯斐波那契扩展
   → 置信度 = "低"（仅结构支撑）

ELSE（方向冲突）
   → 输出 "观望"，不给出价格目标
```

### 4. 触发/失效条件

| 维度 | 触发条件 | 失效条件 |
|------|---------|---------|
| **价格** | 日线收盘价突破颈线/前高/关键枢轴 | 反向跌破形态起点或前低支撑 |
| **趋势** | 周线ADX > 25 且 +DI > -DI | 周线ADX 回落至 20 以下 |
| **量能** | 突破日成交量 > 20日均量 × 1.3 | 目标区间内量能连续3日萎缩 |

### 5. 报告输出格式

```markdown
## 价格目标与触发条件

**方向**: 中线看多 | **置信度**: 高（日K双底 + 周K波段扩展 共振）

| 目标 | 价格 | 推导依据 | 验证源 |
|------|------|---------|--------|
| 保守 | 135.0 | 周K斐波那契1.0位 + 日K前高 | 周线结构 |
| 基准 | 148.0 | 日K双底测距 = 周K1.272扩展 | A+B交叉验证 |
| 激进 | 162.0 | 周K斐波那契1.618扩展 | 周线大结构 |

**触发**: 日线收盘站稳128.5 + 周线ADX>25 + 当日量>1.3×20日均量
**止损**: 日线收盘跌破118.0 或 周线ADX<20
**时间预期**: 保守2-4周 / 基准1-2月 / 激进2-3月
```

## 关键算法

### 斐波那契扩展
```python
def fib_extension(low, high, level):
    """从波段低点到高点的斐波那契扩展"""
    return high + (high - low) * (level - 1)
    # level: 1.0, 1.272, 1.618
```

### 形态测距
```python
def pattern_target(neckline, top, is_bullish):
    """双顶/双底测距"""
    height = abs(top - neckline)
    return neckline + height if is_bullish else neckline - height
```

### 置信度矩阵

| 日K | 周K | 置信度 | 说明 |
|-----|-----|--------|------|
| 形态+ | 形态+ | 高 | 双时间框架形态确认 |
| 形态+ | 波段 | 中 | 单形态验证 |
| 波段 | 形态+ | 中 | 单形态验证 |
| 波段 | 波段 | 低 | 纯斐波那契支撑 |
| 冲突 | 任意 | 观望 | 不做目标 |

## 边界情况处理

1. **无足够历史数据**（新股或停牌）：跳过价格目标板块，报告标注"数据不足"
2. **股价处于历史极端位置**：斐波那契扩展可能产生不合理数值，用 3×ATR 做上限截断
3. **港股支持**：黑芝麻智能等港股通过 Wind CSV 导入周K数据，接口保持一致
4. **横盘无趋势**：ADX < 20 持续超过4周，自动输出"震荡格局，暂不做目标"
