# 报告格式与数据体系升级方案

> 日期：2026-05-29
> 来源：AlphaGBM Skills 分析启发 + 雪球/知乎爬虫实战经验

---

## 一、背景

### 1.1 当前报告的现状

当前个股舆情报告（以 `stock_reporter.py` 为核心）结构如下：

```
# 个股报告结构
1. 估值与业绩预测（腾讯财经 + 同花顺一致预期）
2. 技术面分析（mootdx + stockstats）
3. 最新研报摘要（东财）
4. 近期公告要点（巨潮/akshare）
5. 资金流向追踪（akshare）
6. 知乎内容精选（知乎API + ZhihuCurator）
7. 市场情绪与竞争格局（雪球帖子双轨分流）
8. 核心话题与产业逻辑（硬编码模板）
9. 精品帖子深度解读（雪球 featured + LLM判断）
10. 关键评论摘录（雪球帖子）
11. 风险提示与关注要点（硬编码模板）
```

**存在的问题**：
- 估值判断是**定性描述**（"估值消化""PEG偏高"），缺乏**量化综合评分**
- 风险提示是**高/中/低文字**（"短期涨幅过大回调风险（高）"），没有**0-10 量化风险分**
- 没有**目标价区间**（乐观/基准/悲观三档）
- 没有**AI 综合推荐**（一句话 actionable 建议）
- 雪球帖子质量参差，缺少**股票级质量评估**
- 知乎内容已有 ZhihuCurator 三层过滤，但**全网搜索**尚未接入
- 没有 **Investment Thesis（投资论据）** 和 **Health Check（研究库体检）**

### 1.2 AlphaGBM 的启发

AlphaGBM 的 26 个 skills 中，对我们最具参考价值的是：

1. **G = B + M 综合评分模型**（Gain = Basics + Momentum）
2. **标准化输出结构**（Recommendation + Target Price + Risk Score + EV Score）
3. **Knowledge Base 体系**（Company Profile + Investment Thesis + Theme Research + Health Check）
4. **Skills 串联 Workflow**（Stock Analysis → Options Score → Strategy Builder）
5. **风险评分加法模型**（0-10，每个因子有明确触发条件和加分值）

## 二、升级方案（分阶段）

### Phase 0: 雪球内容质量修复（已完成，需保持）

**问题**：雪球列表页只显示 truncated 摘要，短帖和长文摘要混在一起，低质量帖子进入 Vault 和报告。

**已实现的修复**：
- `content_quality.py` 双轨分流：featured（高质量长文）vs sentiment（短帖情绪）
- `fetcher.py` 二次过滤：详情页正文 < 150 字降级为 sentiment
- `stock_reporter.py` 三次过滤：口号检测 + LLM 负面过滤 + Vault 正文质量检查
- 乐鑫科技/圣邦股份实测：featured 4/6 条，LLM 过滤后 2-3 条进入报告

**待优化**（后续 revisit）：
- 股票级质量评估：如果整只股票 featured 候选 < 3 条或平均长度 < 150 字，直接判定"社区质量不足"
- 列表页 truncated 摘要识别：以 "..." 结尾但长度 < 150 字的帖子，不触发条件 A

### Phase 1: 知乎内容精编（已完成核心部分）

**问题**：知乎板块之前是简单列表展示（标题+300字截断），无质量评估、无深度摘要。

**已实现的修复**：
- 新增 `zhihu_curator.py`：三层漏斗（L1 cutoff → L2 DeepSeek 批量评分 → L3 时效过滤）
- `ZhihuCollector.collect()` 集成 curator，默认启用
- `_zhihu_section()` 升级渲染：质量分、摘要、逻辑链（前提→论据→推理→结论）、AI 判断

**后续方向 2-3**（待实现）：
- 方向 2：接入全网搜索（Tavily/SerpAPI/Bing + 微信公众号 + 雪球专栏）
- 方向 3：股票级搜索策略（从 `config/stocks.json` 自动推导关键词：圣邦→模拟芯片/国产替代/杰华特）

### Phase 2: 报告量化评分体系（P0 — 立即可以做）

#### 2.1 综合评分：G = B + M（A股版）

AlphaGBM 用 G = B + M（Gain = Basics + Momentum），我们改为 A股适用的五维度：

| 维度 | 权重 | 数据源 | 说明 |
|------|------|--------|------|
| **估值健康度 (B)** | 30% | 腾讯财经 PE/PB + 同花顺一致预期 | Forward PE 消化幅度 × PEG 健康度 |
| **技术面强度 (M)** | 25% | mootdx + stockstats | RSI/MACD/均线/成交量综合 |
| **情绪面温度 (M)** | 20% | 雪球帖子 sentiment | 看多/看空比例、互动热度 |
| **基本面趋势 (B)** | 15% | 同花顺一致预期 EPS | 预期增速、覆盖机构数 |
| **资金关注度 (M)** | 10% | akshare 资金流向 | 主力净流入、板块资金 |

**输出**：
- 综合评分 0-100（或 0-10，与 AlphaGBM 对齐）
- 信号等级：STRONG_BUY / BUY / HOLD / AVOID / STRONG_AVOID
- 置信度：基于数据完整度（如有缺失数据，置信度降低）

#### 2.2 目标价区间（三档）

| 情景 | 计算方式 | 说明 |
|------|---------|------|
| 乐观 | Forward PE × 2027 预期 EPS × 1.2 | 情绪溢价 |
| 基准 | Forward PE × 2027 预期 EPS | 中性估值 |
| 悲观 | Forward PE × 2027 预期 EPS × 0.7 | 风险折价 |

**输出**：
- 三档目标价 + 相对当前价的潜在涨跌 %
- 当前价在 52 周区间中的位置

#### 2.3 风险评分 0-10（加法模型）

| 风险因子 | 触发条件 | 加分 | 当前报告对应 |
|----------|---------|------|-------------|
| 估值过高 | Forward PE > 行业均值 2 倍 或 PEG > 2 | +2 | "PEG 偏高" |
| 涨幅过大 | 近一月涨幅 > 30% | +2 | "短期涨幅过大" |
| 情绪过热 | 雪球看多帖子占比 > 80% | +1.5 | 情绪定级"看多" |
| 技术破位 | 股价 < 20 日均线 | +1 | 技术面"均线空头" |
| 板块衰退 | 所属板块近一周跌幅 > 5% | +1 | — |
| 流动性差 | 日均成交额 < 5 亿 | +1 | — |
| 宏观逆风 | 大盘近一月跌幅 > 10% | +1.5 | — |

**风险等级与仓位建议**：

| 分数 | 等级 | 建议 |
|------|------|------|
| 0-2 | 低风险 | 积极配置，最大仓位 20% |
| 3-5 | 中等风险 | 谨慎持有，仓位 10-15% |
| 6-7 | 高风险 | 控制仓位，5-10% |
| 8-10 | 极高风险 | 建议减仓或不买入 |

**输出位置**：替换当前「五、风险提示与关注要点」板块，改为：
```markdown
## 五、综合风险评分

### 风险等级: 4/10（中等风险）

| 风险因子 | 状态 | 加分 |
|----------|------|------|
| 估值过高 | Forward PE 95 > 行业均值 2 倍 | +2 |
| 涨幅过大 | 近一月涨幅 +45% > 30% | +2 |
| 情绪过热 | 看多占比 80% | 0 |
| ... | ... | ... |

### 关注要点
- 能否站稳 100 元关口
- 思瑞浦等同业走势
- ...
```

#### 2.4 AI 综合推荐

在报告最开头（紧接综合评分后），增加一句话 actionable 建议：

```markdown
> **AI 综合推荐**：模拟芯片周期反转+国产替代双击窗口，圣邦作为龙头享有估值溢价。
> 当前风险 4/10 中等，建议持有但不再追高。若回调至 90 元以下（20 日均线），可考虑加仓。
```

生成方式：基于综合评分、风险分、估值判断、技术面、情绪面，用 LLM 生成 100-150 字推荐语。

### Phase 3: Knowledge Base 体系（P1 — 近期实现）

#### 3.1 Investment Thesis（投资论据）

**功能**：在 Vault 中为每只股票记录买入理由和结构化卖出条件。

**数据结构**：
```json
{
  "stock_name": "圣邦股份",
  "buy_thesis": "模拟芯片周期反转+国产替代双击，圣邦作为龙头最受益",
  "sell_conditions": [
    {"type": "price_drop_pct", "value": 20, "note": "从买入价下跌 20%"},
    {"type": "pe_above", "value": 120, "note": "Forward PE 超过 120"},
    {"type": "growth_below", "value": 20, "note": "预期增速低于 20%"},
    {"type": "thesis_breach", "value": "杰华特在 MOS 领域市占率超过圣邦", "note": "竞争格局恶化"}
  ],
  "status": "active",
  "created_at": "2026-05-20",
  "updated_at": "2026-05-27"
}
```

**自动化检查**：每次生成报告时：
1. 读取该股票的 Investment Thesis
2. 检查卖出条件是否触发
3. 如果触发，在报告中高亮提示：「⚠️ 投资论据偏离：杰华特 MOS 市占率已超过圣邦，建议重新评估持仓」

**存储位置**：`knowledge/10-Stocks/{stock_name}/thesis.json`

#### 3.2 Health Check（研究库体检）

**功能**：每周自动扫描 Vault，评估研究库的完整性和时效性。

**检查项**：

| 类别 | 检查内容 | 阈值 |
|------|---------|------|
| 过期档案 | 技术指标笔记超过 7 天未更新 | > 7 天 |
| 过期档案 | 研报笔记超过 90 天未更新 | > 90 天 |
| 论据偏离 | Investment Thesis 中的增速假设 vs 最新一致预期偏差 | > 20% |
| 孤立主题 | 有 Company Profile 但没有 Thesis 的股票 | 存在即报警 |
| 空仓信号 | 有 Thesis 但近 30 天未生成报告的股票 | > 30 天 |

**输出**：
```markdown
# 研究库体检报告 (2026-05-29)

## 综合健康分: 78/100 (良好)

### 需关注项
- 🔴 [圣邦股份] 论据偏离：Thesis 假设 2026 增速 40%，最新一致预期仅 32%，偏差 -20%
- 🟡 [乐鑫科技] 技术指标笔记已 10 天未更新
- 🟡 [黑芝麻智能] 有 Profile 但无 Investment Thesis

### 建议操作
1. 重新评估圣邦股份 Thesis，考虑下调增速假设或减仓
2. 更新乐鑫科技技术指标
3. 为黑芝麻智能补充 Investment Thesis
```

**执行方式**：新增 `scripts/health_check.py`，支持手动执行或定时任务。

#### 3.3 Compare 升级（可比公司量化对比）

当前「竞争格局对比」是文字描述，升级为量化对比表：

```markdown
### 可比公司量化对比

| 公司 | 最新价 | PE(TTM) | Forward PE | PEG | 近一月涨幅 | 雪球情绪分 | 风险分 |
|------|--------|---------|------------|-----|-----------|-----------|--------|
| 圣邦股份 | 123.50 | 125.5 | 95.0 | 2.52 | +45% | 7.2 | 4/10 |
| 思瑞浦 | 98.20 | 88.3 | 72.0 | 2.10 | +38% | 6.8 | 3/10 |
| 杰华特 | 45.60 | - | 65.0 | - | +52% | 8.1 | 5/10 |
| 纳芯微 | 156.30 | 92.1 | 70.0 | 1.85 | +30% | 6.5 | 3/10 |
| 艾为电子 | 72.10 | 45.6 | 40.0 | 1.20 | +22% | 5.9 | 2/10 |

**结论**：圣邦估值最高（Forward PE 95），但情绪面最强。艾为电子估值最低、风险最小。
```

数据源：腾讯财经批量获取（已有 `_fetch_tencent_quote` 函数）。

### Phase 4: 主题研究与情绪 dashboard（P2 — 中期规划）

#### 4.1 Theme Research（产业主题分组）

**功能**：按产业主题分组跟踪多只股票，生成主题级报告。

**示例主题**：
- **物理 AI**：三花智控（机器人执行器）+ 圣邦股份（模拟芯片）+ 乐鑫科技（端侧 AI）
- **智驾芯片**：黑芝麻智能 + 地平线
- **碳纤维军工**：中简科技 + 光威复材
- **生长激素**：长春高新 + 特宝生物

**主题报告内容**：
- 主题内各股票综合评分对比
- 主题级资金流向（板块主力资金净流入）
- 主题级舆情热度（雪球讨论总量、情绪分布）
- 催化剂日历（各公司财报、产品发布、行业展会）

**存储**：`knowledge/Themes/物理AI/MOC.md`

#### 4.2 Market Sentiment Dashboard（A股版）

AlphaGBM 用 VIX / PutCall / FearGreed，A股没有直接对应指标，可以用：

| A股指标 | 数据源 | 对应 AlphaGBM |
|---------|--------|--------------|
| 北向资金流向 | akshare | VIX（外资情绪） |
| 融资融券余额变化 | akshare | Put/Call Ratio（杠杆情绪） |
| 涨停/跌停家数 | akshare | Market Breadth（市场宽度） |
| 板块轮动热度 | 同花顺热点 | Sector Rotation |
| 雪球全站情绪 | 雪球爬虫 | Fear & Greed Index |

**输出**：
```markdown
### A股市场情绪仪表盘

| 指标 | 数值 | 信号 |
|------|------|------|
| 北向资金 | +88.8亿 | 流入（偏多） |
| 融资余额 | +45.2亿 | 增加（杠杆上升） |
| 涨停/跌停 | 85/12 | 偏多 |
| 半导体板块资金 | +177.6亿 | 大热 |
| 雪球情绪指数 | 68/100 | 偏乐观 |

**市场状态**: 风险偏好在高位，注意追高风险。
```
