# 雪球爬虫内容质量门控设计

## 背景与问题

当前 `XueqiuFetcher` 抓取流程：
1. 打开股票讨论页 → 点击"讨论" tab → 点击"热门排序"
2. 从列表页提取最多 15 条帖子
3. 对 Top 3 高互动帖子进入详情页提取正文
4. 所有内容无差别写入 Vault 和报告

问题：
- 列表页仅浏览 1 页，采样范围窄
- 短内容/口号式帖子无过滤，直接污染 Vault 和报告
- 详情页请求浪费在大量低质量帖子上

## 目标

1. **扩大采样范围**：列表页浏览 5-10 页热帖
2. **前置质量分流**：列表页阶段区分"长文候选"与"短帖情绪"
3. **减少 Vault 污染**：仅高质量长文写入 Vault
4. **保留情绪价值**：短帖仍参与情绪统计，但不进入详情页/Vault/报告精品帖

## 架构

```
列表页 (5-10页, ~100-200条)
    │
    ├─ 轨道 A: 长文精选 ──→ 详情页提取 ──→ Vault + 报告精品帖
    │   筛选: 摘要以"..."结尾 / 含数据+逻辑词 / 互动>30
    │
    └─ 轨道 B: 短帖情绪 ──→ 情绪统计 ONLY
        筛选: 无"..."且<80字 / 纯情绪表达
        不进入: 详情页 / Vault / 报告精品帖
```

## 筛选规则

### 轨道 A — 长文精选

满足**任一**条件即可进入详情页候选池：

| 条件 | 说明 | 权重 |
|---|---|---|
| `摘要 endswith("...")` | 雪球 UI 截断信号，高概率长文 | 必须 |
| 含数据+逻辑词 | 列表页摘要包含数字/百分比 + "因为"/"所以"/"如果"等 | 加分 |
| 互动数 > 30 | 点赞+评论 > 30，社区关注度高 | 加分 |

候选池按 `(like_count + comment_count)` 排序，Top 5-10 条进入详情页。

详情页抓取后二次过滤：
- 正文 < 80 字 → 降级到轨道 B（参与情绪统计，不写入 Vault）
- 正文 ≥ 80 字 → 写入 Vault，进入报告"精品帖子深度解读"

### 轨道 B — 短帖情绪

满足**全部**条件：
- 列表页摘要不以 `"..."` 结尾
- 列表页摘要长度 < 80 字
- 不含数据+逻辑词组合

用途：
- 参与情绪分类（看多/看空/中性）
- 参与情绪定级计算
- **不进入详情页**
- **不写入 Vault**
- **不进入报告精品帖子**

## 数据流变更

| 步骤 | 当前 | 新流程 |
|---|---|---|
| 列表页浏览 | 1 页 (~15条) | 5-10 页 (~100-200条) |
| 列表页筛选 | 无 | 双轨分流 |
| 详情页请求 | Top 3 全部进 | 仅长文候选 Top 5-10 |
| Vault 写入 | 所有详情页内容 | 仅正文 ≥ 80 字 |
| 报告精品帖 | 可能混入短内容 | 仅高质量长文 |
| 情绪分析 | 基于全部 | 基于全部（短帖也参与）|

## 反爬策略

- 列表页翻页间隔：2-3 秒
- 详情页请求间隔：3-5 秒
- 单只股票总详情页请求 ≤ 10 次
- 使用已有的 `_human_like_interaction` 模拟真人浏览

## 接口变更

### `XueqiuFetcher.fetch_stock_posts`

```python
def fetch_stock_posts(
    self,
    stock_code: str,
    stock_name: str,
    max_list_pages: int = 10,      # 新增：列表页浏览页数
    max_detail_posts: int = 10,    # 修改：最多进详情页的帖子数
    fetch_comments: bool = True,
) -> Dict[str, List[Dict]]:        # 返回格式变更
    """
    Returns:
        {
            "featured": [...],   # 长文精选（含完整正文）
            "sentiment": [...],  # 短帖情绪（仅列表页摘要）
        }
    """
```

### `DetailPageFetcher`

无需修改，继续处理长文候选的详情页提取和 Vault 写入。

### `PerStockReporter`

- `stocks_data` 结构不变，但来源变为 `featured + sentiment` 的合并
- 精品帖子仅使用 `featured` 中的帖子
- 情绪分析使用全部帖子

## 边界情况

1. **刚好 79 字的高质量帖子**：被 `"..."` 信号漏掉的风险。缓解：互动数 > 30 的帖子即使无 `"..."` 也进入候选池。
2. **所有帖子都是短内容**：候选池为空时，报告"精品帖子"章节显示"本期无高质量分析帖"。
3. **详情页抓取失败**：记录失败，不影响其他帖子。

## 成功标准

- [ ] 单只股票浏览 ≥ 5 页列表页
- [ ] Vault 中无 < 80 字的帖子
- [ ] 报告精品帖子全部为正文字数 ≥ 80 的长文
- [ ] 情绪分析仍基于全部帖子（含短帖）
