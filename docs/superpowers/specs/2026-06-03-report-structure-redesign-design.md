# 报告结构重塑与重复消除设计方案

> **Goal**: 重构个股报告的板块结构，消除重复事实陈述，增加执行摘要让阅读更有层次

**Architecture**: 采用"总-分"式阅读架构——执行摘要（总览）→ 事实基座（数据源）→ 深度分析（推理与判断）。深度分析板块从5个合并为3个，各自聚焦不同推理维度。

**Tech Stack**: 现有 stock_reporter.py + KnowledgeSynthesizer 体系，仅调整板块编排和 Prompt 策略

---

## 一、当前问题诊断

### 1.1 重复事实罗列（已确认）
以黑芝麻智能 2026-06-02 报告为例，以下事实在 5 个板块中重复出现：

| 事实 | 出现板块 |
|------|----------|
| 2025年营收8.22亿元，同比+73.4% | 三、四、五、六、七 |
| 毛利率41% vs 地平线64.5% | 三、四、五、六、七 |
| C1236芯片单颗便宜200-300元，进入比亚迪供应链 | 三、四、五、七 |
| 2025年具身智能收入近1亿元，毛利率48.7% | 三、四、五、七 |
| 2025年2月13日解禁抛压 | 四、五、六、七 |
| 管理层指引2026年收入增长80% | 四、五、七 |

### 1.2 缺乏阅读层次
当前报告直接以"综合评分"进入，读者无法快速把握：看多理由是什么？看空理由是什么？关键风险在哪？

## 二、新报告结构（7大模块）

### 模块1：执行摘要（Executive Summary）← 新增

**定位**：读者 30 秒内把握全貌的"一页纸"

**内容构成**：
1. **综合评分卡片**：当前评分、评级、仓位建议（保留现有逻辑）
2. **核心投资论点**（看多/看空各 3-4 条）：
   - 每条论点必须包含：判断 + 关键数据支撑 + 风险/机会等级（⭐1-5）
   - 示例：
     - 看多：C1236芯片获比亚迪定点，单颗成本较竞品低200-300元，性价比优势显著 → ⭐⭐⭐⭐
     - 看空：毛利率41%远低于地平线64.5%，规模仅为对手1/4，缺乏定价权 → ⭐⭐⭐⭐⭐
3. **一句话结论**：如"高弹性与高风险并存，等待2026H1盈利拐点验证"

**Prompt 策略**：基于 KnowledgeSynthesizer 的 5 个主题合成结果，提取最关键的多空论据，各限 4 条以内，强制要求带数据支撑。

### 模块2：估值与财务快照 ← 精简

**定位**：只看数据，不讲故事

**内容构成**：
1. 实时估值指标（表格：最新价、总市值、PE/PB/PS）
2. 竞争对手财务对比（表格：存货周转、应收周转、毛利率、PE、PS 等）
3. **一句话判断**：如"PS 13.4x 处于行业中游水平"

**删除项**：
- 原"券商一致预期"的长篇叙述段落
- "判断"段落中的基本面展开（移到深度分析模块）

### 模块3：核心事实基座（Core Facts）← 新增

**定位**：所有后续深度分析的"数据源"，读者有疑问时回查

**格式**：编号表格

```markdown
### 核心事实基座

| # | 事实 | 数据/来源 | 置信度 |
|---|------|-----------|--------|
| 1 | 2025年营收 | 8.22亿元，同比+73.4% | 年报（高） |
| 2 | 毛利率 vs 地平线 | 41% vs 64.5%，落后23pp | 年报（高） |
| 3 | C1236芯片价格优势 | 单颗较竞品低200-300元 | 雪球讨论（中） |
| 4 | 比亚迪供应链定点 | C1236已进入比亚迪供应链 | 雪球讨论（中） |
| 5 | 具身智能收入 | 2025年近1亿元，毛利率48.7% | 年报（高） |
| 6 | 2026年收入指引 | 管理层指引增长80%，目标约14.8亿 | 雪球讨论（中） |
| 7 | 研发开支 | 2025年14.17亿元，远超营收 | 年报（高） |
| 8 | 解禁抛压 | 2025年2月13日上市前投资者解禁 | 雪球讨论（高） |
```

**生成方式**：
- 由 KnowledgeSynthesizer 在合成各主题时同步提取关键事实
- 事实去重：同一事实在不同主题中出现时只保留一条
- 置信度标注：高（年报/公告）、中（雪球大V/研报）、低（社区传言）

**关键约束**：后续深度分析模块**不得再展开这些数据**，只聚焦"事实意味着什么"。引用格式：`（见事实#1）`

### 模块4：深度分析（合并原 3/4/5/6/7）

**定位**：聚焦推理和判断，不重复数据

**4.1 产业逻辑与竞争格局**
- 行业趋势（舱驾一体、降本需求）
- 竞争定位（C系列 vs 地平线 vs 比亚迪自研 vs Mobileye）
- 差异化壁垒评估
- 关键变量判断（如：舱驾一体芯片能否锁定更多车企订单）
- *引用格式：毛利率差距显著（见事实#2），C1236性价比切入中低端市场（见事实#3、#4）*

**4.2 业绩路径与多空分歧**
- 增长引擎（比亚迪放量、具身智能、亿智并表）
- 盈利拐点分析（亏损何时收窄、毛利率何时改善）
- 看多 vs 看空的核心分歧点
- *引用格式：管理层指引增长80%（见事实#6），但研发烧钱率仍高（见事实#7）*

**4.3 资金面与催化剂时间线**
- 资金博弈（解禁抛压 vs 基本面改善）
- 关键时间节点（半年报、新定点公告、行业政策节点）
- 需要跟踪的信号（回购公告、港股通持仓变化、新主机厂定点）
- *引用格式：解禁抛压持续（见事实#8），下一个催化是2026半年报（见事实#6）*

**合并逻辑**：
- 原"产业逻辑" + "业绩基本面" → 4.1（产业层面的长期判断）
- 原"估值争议" + "业绩基本面中的增长引擎" → 4.2（业绩路径与多空博弈）
- 原"资金面" + "关键事件" → 4.3（短期催化剂与跟踪信号）

**Prompt 策略调整**：
- 在调用 KnowledgeSynthesizer 时，传入 `no_repeat: true` 指令，要求只输出推理和判断，不重复原始数据
- 合成文本中要求使用引用格式引用事实编号

### 模块5：行业特有风险因子评估（保持）

现有 `industry_specific_risk_table()` 逻辑不变，继续为特定行业（如亏损芯片股）生成风险因子表格。

### 模块6：综合风险评分与仓位建议（保持）

现有 `risk_score_section()` 逻辑不变，但评分描述中可引用事实编号增强说服力。

### 模块7：信息来源汇总（保持）

现有 citation 汇总逻辑不变。

## 四、Self-Review

### 4.1 Spec Coverage

| 需求 | 对应模块 |
|------|----------|
| 减少重复事实陈述 | 模块3（事实基座）+ 模块4（深度分析只讲推理） |
| 开头有要点总结 | 模块1（执行摘要：看多/看空论点） |
| 利好与风险速览 | 模块1（投资论点卡片，带星级） |
| 阅读有层次 | 总览 → 数据 → 推理 → 风险评估 |
| 板块合并 | 原5个合成板块 → 3个深度分析子板块 |

### 4.2 Placeholder Scan

无 TBD/TODO/"implement later"。所有模块有明确的输入来源和输出格式。

### 4.3 Type Consistency

- `KnowledgeSynthesizer.synthesize()` 新增 `core_facts` 字段为 `List[Dict]`，与现有 `citations` 字段格式一致
- `PerStockReporter.generate_stock_report()` 内部 `sections` 列表组装逻辑不变，仅替换部分 section 生成方法

### 4.4 Scope Check

本设计聚焦报告结构重塑，不涉及：
- 数据采集流程修改
- 评分算法修改
- PDF 渲染修改
- 数据源扩展（Wind、Fact Check）

这些属于方向2/3，将在本设计实施后另行推进。
