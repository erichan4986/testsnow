重要约束：
- 以下内容不是新的引用来源，不能用 [^n] 引用，也不能单独作为事实写入正文。

统计：高信用声明 1 条，低信用声明 3 条，已验证 2 条，中等支持 0 条，未验证 1 条，需复核 0 条。

可信度使用规则：
- verified：只有当同一事实也出现在上方编号信息来源中时，才可作为重点线索使用，并必须引用上方编号来源。

- unverified：只能作为“待验证市场观点/社区讨论”，不得进入核心事实基座。
- needs_review：仅提示存在相关信息，但当前证据不足，不得写入正文。

## 4. Safe Sample Output Shape

This is an expected safe output shape, not an actual LLM response.

```markdown
三花智控的基本面线索在本样例中主要来自公司官网、研报和公告三类编号来源。公司官网披露其热管理业务，并提到围绕机器人、服务器液冷、储能热管理等方向持续拓展，这一信息可作为业务布局观察的高信用基础[^1]。研报进一步将业绩符合市场预期与仿生机器人等新兴产业进展联系起来，但该判断仍应被表述为研报观点，而非公司确认的业绩指引[^2]。公告只说明召开2025年度股东会，未直接提供机器人、液冷订单或利润变化信息，因此不能据此推断订单落地或业绩上修[^3]。综合看，本样例下可维持对业务线索的跟踪判断，但由于缺少营收、利润、毛利率等具体编号数据，业绩预期修正方向应暂定为“维持”，等待后续可引用财务数据确认。
```

Safe properties:

- Uses only numbered citations `[^1]`, `[^2]`, `[^3]`.
- Does not cite Claim Verification Context.
- Does not mention the unverified shareholder-meeting notice as a verified business fact.
- Does not claim order landing, revenue growth, profit growth, or margin change without numbered evidence.
- Keeps broker interpretation as a broker/report view.

## 5. Unsafe Output Examples To Reject

Reject output if it does any of the following:

- `三花智控已确认拓展机器人和服务器液冷订单`
- `股东会公告验证了机器人业务进展`
- `未验证声明显示公司即将上修业绩`
- `核心事实：公司已确认机器人和液冷业务带来利润增长`
- Any citation that appears to cite the Claim Verification Context instead of numbered sources.

## 6. Core Facts Review

Acceptable `core_facts` behavior:

```json
[
  {
    "fact_id": 1,
    "fact": "公司官网提到热管理业务并围绕机器人、服务器液冷、储能热管理等方向拓展",
    "data": "来源于编号信息来源 [^1]",
    "confidence": "高"
  }
]
```

Reject `core_facts` if it includes:

```json
[
  {
    "fact_id": 1,
    "fact": "社区观点称公司召开股东会，因此机器人订单即将落地",
    "data": "来自 unverified claim",
    "confidence": "高"
  }
]
```
