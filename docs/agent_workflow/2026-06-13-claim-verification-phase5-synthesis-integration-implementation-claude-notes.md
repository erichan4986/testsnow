# Claude Notes: Claim Verification Phase 5 Synthesis Integration

## Fix Round: Default Knowledge Base Path

### Issue

Codex review found that `SynthesisSkill._build_claim_verification_context()` defaulted to the bare string `"knowledge"`, making the default cwd-dependent. When reports are run from `scripts/`, the builder would look at `scripts/knowledge` instead of the repo root `knowledge/`.

### Change

- `scripts/utils/report_skills/synthesis_skills.py`:
  - Imported `Path`.
  - Added repo-root resolver in `_build_claim_verification_context()`: when `claim_verification_base_dir` is not explicitly provided, default to `Path(__file__).resolve().parents[3] / "knowledge"`.
  - Passed the resolved path as `str(base_dir)` to `build_claim_verification_plan()`.

- `tests/reporter/test_synthesis_skills.py`:
  - Added `test_default_base_dir_resolves_to_repo_root_knowledge()` which enables claim verification without passing `claim_verification_base_dir`, captures the context during `_build_claim_verification_context`, and asserts the ctx has no explicit base dir and the run resolves to repo-root `knowledge/` (status `empty` for a non-existent test stock).

## Summary

Implemented optional, default-off claim verification context for Phase 5 synthesis integration. The change lets `SynthesisSkill` pass a sanitized, non-citable verification summary into both the modern `KnowledgeSynthesizer` path and the legacy `.chat(prompt)` path. It does not add new numbered citation sources, does not write to `knowledge/`, and does not change report behavior unless `enable_claim_verification_context=True`.

## Sample Prompt Appendix

Generated by a temporary fixture with one high-credit evidence note and one low-credit social note. No LLM was called.

```text
Claim Verification Context（以下不是新的引用来源）

重要约束：
- 以下内容不是新的引用来源，不能用 [^n] 引用，也不能单独作为事实写入正文。
- 它只用于判断社区观点的可信度，帮助你决定如何强调或弱化某些信息。

统计：高信用声明 1 条，低信用声明 3 条，已验证 2 条，中等支持 0 条，未验证 1 条，需复核 0 条。

可信度使用规则：
- verified：只有当同一事实也出现在上方编号信息来源中时，才可作为重点线索使用，并必须引用上方编号来源。
- supported：可描述为“有中等信用来源支持的线索”，但不得写成已确认事实。
- unverified：只能作为“待验证市场观点/社区讨论”，不得进入核心事实基座。
- needs_review：仅提示存在相关信息，但当前证据不足，不得写入正文。

已验证声明：
- [verified] 三花智控研报线索：三花智控2026年一季报点评：业绩符合市场预期，仿生机器人等新兴产业蓄势待发 （置信度 82） [依据标题: 三花智控官方业务介绍] [原因: specific terms: 机器人]
- [verified] 三花智控研报线索：三花智控2025年净利润较快增长，拓展机器人、服务器液冷等新领域 （置信度 82） [依据标题: 三花智控官方业务介绍] [原因: specific terms: 机器人, 液冷]

未验证声明：
- [unverified] 三花智控公告线索：三花智控：关于召开2025年度股东会的通知 （置信度 20） [原因: no high or medium credit source with matching topic and terms]
```
